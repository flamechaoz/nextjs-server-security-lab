## What you'll learn

- Identify common trust-boundary failures.
- Use safe rendering and parameterized data access.
- Choose suitable request and origin protections.

### Treat input as hostile

Validate input at the boundary, use safe rendering, avoid unsafe HTML injection, and use parameterized database operations. Validation should complement—not replace—safe APIs.

### Browser requests have security context

Cookie-authenticated state changes need a CSRF strategy. CORS controls browser access to responses; it is not authentication and does not stop every cross-origin request.

## Walkthrough

1. Review any use of dangerouslySetInnerHTML or dynamic redirects.
2. Inspect database query construction for string concatenation.
3. Identify state-changing endpoints that rely on cookies.
4. Document rate-limit and request-size controls appropriate to deployment.
