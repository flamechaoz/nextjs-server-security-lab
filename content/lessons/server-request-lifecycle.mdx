## What you'll learn

- Explain file-system routing in the App Router.
- Locate a Route Handler from its URL.
- Inspect an HTTP response and its JSON body.

### A URL maps to a file

In the App Router, folders define URL segments. A route.ts file exports HTTP method handlers for that route. The handler is server code; it does not run in the browser.

### Inspect before changing code

Start with the request and response. Check the status, content type, and JSON body, then search the repository for the handler.

## Walkthrough

1. Start the app with npm run dev.
2. Visit /api/hello and inspect the JSON response.
3. Open app/api/hello/route.ts in your editor.
4. Change the message field, save, and refresh the endpoint.
5. Explain why this code runs on the server.
