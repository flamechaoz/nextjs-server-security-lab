## What you'll learn

- Test unauthenticated and unauthorized cases.
- Assert protected services are not called on denial.
- Cover cross-user resource access.

### Negative tests matter

Security tests must prove forbidden actions do not happen. A 403 assertion alone may miss a mutation that was already executed before the response was returned.

### Test the boundary and side effects

Mock or observe the protected service and assert it was not called when identity or permission checks fail.

## Walkthrough

1. Identify protected task operations.
2. Write tests for missing session and different resource owner.
3. Assert the protected mutation was not called.
4. Verify stored data remains unchanged after a denied request.
