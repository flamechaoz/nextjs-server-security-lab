## What you'll learn

- Implement a GET and POST handler.
- Parse a request body safely.
- Choose meaningful HTTP status codes.

### One route, several methods

A route.ts file can export GET, POST, PATCH, DELETE, and other supported HTTP method functions. Each handler should have one clear responsibility.

### The response is part of the API

A correct API communicates success and failure through status codes and stable response shapes, not only through message text.

## Walkthrough

1. Open app/api/tasks/route.ts.
2. Compare GET and POST behavior.
3. Open `/route-handlers-http` and send a POST request with a JSON body.
4. Inspect the response status and returned task object in the playground.
5. Try a malformed body and observe the error response.

### Code walkthrough: `app/api/debug/lesson-03/route.ts`

```tsx
export async function GET() {
  return Response.json({ data: [] });
}

export async function POST(request: Request) {
  const body = await request.json();
  return Response.json({ data: body }, { status: 201 });
}
```
