## What you'll learn

- Call exported handlers with Request objects.
- Test successful and invalid requests.
- Mock service dependencies where appropriate.

### Test the HTTP contract

Route Handler tests should assert the externally observable status, headers, and response body. Include invalid JSON, invalid schema, not-found, and success cases.

### Do not require a live database

A route test can mock a service boundary or use a controlled in-memory implementation. Reserve live infrastructure for integration tests.

### Code walkthrough: `app/api/tasks/route.ts`

```tsx
const request = new Request("http://localhost/api/tasks", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ title: "Read docs" }),
});
const response = await POST(request);
expect(response.status).toBe(201);
```
