## What you'll learn

- Render components in JSDOM.
- Query by role and accessible name.
- Test loading, success, and error states.

### Prefer user-visible contracts

React Testing Library encourages queries that resemble how a user or assistive technology finds elements, such as roles and accessible names.

### Avoid brittle implementation tests

Tests should usually avoid depending on private state, incidental class names, or component internals. Assert on visible behavior and accessible semantics.

## Walkthrough
