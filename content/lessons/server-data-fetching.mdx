## What you'll learn

- Fetch data from a Server Component.
- Keep private environment variables server-only.
- Choose caching behavior intentionally.

### Server-to-server calls

A Server Component can call a service or upstream API without exposing private credentials to the browser. Prefer a server-only service module for shared data access.

### Freshness is a decision

Caching and revalidation affect whether users see fresh data. Decide based on the data's requirements rather than relying on assumptions.

## Walkthrough

1. Inspect lib/services/task-service.ts.
2. Identify where data access is separated from UI code.
3. Review .env.example and distinguish public from private variables.
4. Never prefix a secret with NEXT_PUBLIC_.
