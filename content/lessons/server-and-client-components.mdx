## What you'll learn

- Describe Server Components and Client Components.
- Identify when state and event handlers require a client boundary.
- Avoid sending server-only values to the browser.

### Server by default

Components in the App Router are Server Components unless marked with the use client directive. They can read server-side resources and render HTML without shipping their implementation to the browser.

### Client for interaction

Use Client Components for state, effects, event handlers, and browser APIs. Keep the client boundary as small as practical.

## Walkthrough

1. Open app/page.tsx and identify the server-rendered page.
2. Inspect components/TaskManager.tsx for interactive behavior.

4. Move no secrets or server-only dependencies into a client component.

"use client";

import { useState } from "react";

export function ExampleCounter() {
  const [count, setCount] = useState(0);
  return (
    <button onClick={() => setCount(count + 1)}>
      Clicked {count} times
    </button>
  );
}
