## What you'll learn

- Explain dynamic route segments.
- Await params in current App Router handlers.
- Validate route values before using them.

### Dynamic segments

A folder named [id] matches a URL segment such as /api/tasks/12. The segment name becomes a property on params.

### Params may be asynchronous

In current Next.js App Router conventions, params is a Promise in route handler context. Await it before reading the ID.

## Walkthrough

1. Visit /api/tasks/1 and /api/tasks/999.
2. Open app/api/tasks/[id]/route.ts.
3. Trace how context.params is awaited and parsed.
4. Follow the ID into findTask and inspect the response.

### Code walkthrough: `app/api/tasks/[id]/route.ts`

```tsx
type Context = { params: Promise<{ id: string }> };

export async function GET(_request: Request, context: Context) {
  const { id } = await context.params;
  return Response.json({ requestedId: id });
}
```
