## What you'll learn

- Run the existing test suite.
- Use Arrange–Act–Assert.
- Distinguish unit, integration, and end-to-end tests.

### Tests describe behavior

A good test states a behavior, creates the required setup, performs an action, and asserts an observable result. Tests should not depend on execution order.

### Choose the right test boundary

Unit tests isolate a small function. Integration tests verify cooperating parts. End-to-end tests verify a user flow through the running app.

## Walkthrough

1. Run npm test.
2. Open lib/task-rules.test.ts.
3. Map each test to Arrange, Act, and Assert.
4. Add one test for a boundary case.
